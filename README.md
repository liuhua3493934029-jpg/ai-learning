# 学习手记 · 寂静轨道

原生 HTML / CSS / JavaScript 学习站，附三套可切换的视觉主题：经典、WebGL 星空，以及 Canvas 测绘的「山海」。当前课程是 AI 工作流学习路线：20 门课程与 2 条跳过记录。

## 本地运行

在本目录执行：

```sh
python3 start-preview.py
```

脚本会打开 http://127.0.0.1:8000 。如未自动打开，可手动访问；用页边的「经典 / 星空 / 山海」切换。无需构建或下载第三方运行资源。星空主题使用现代浏览器的 WebGL 标准；本轮实际验证使用 Chromium 146。

## 文件

- `index.html`：保留原经典样式、全部课程与学习数据逻辑；新增主题选择和滚动章节。
- `space.css`：隔离的星空主题、章节排版、移动端与无 WebGL 降级。
- `start-preview.py`：仅使用 Python 标准库的本地预览启动器，可用 `--port 8001` 更换端口。
- `tests/space-smoke.cjs`：可复跑的三主题与学习数据回归。
- `space.js`：原生 WebGL 着色器、三维球体光线求交、程序化地表/大气/星云、带阴影和遮挡的三维星环、连续相机轨迹与渲染调度。
- `terrain.css`：隔离的「山海」主题：测绘纸色板、宋体/等宽排印、索引卡、图例侧栏与三档响应式。
- `terrain.js`：确定性地形场与等高线（值噪声 + fbm + 域扭曲、marching squares）、按进度的实线/虚线/朱红当前位置、山巅标记与一次性绘制。

五幕：深空苏醒 → 轨道穿行 → 行星近景 → 星云跃迁 → 原有学习区。首屏可直接跳至学习区，右侧章节导航可跳转，主题选择器始终可达。滚动保持浏览器原生行为。

## 第三套主题：山海

「经典」是一张书桌，「星空」是一片宇宙，「山海」是一张测绘图。它把学习路线画成一张等高线地形图：完成率就是海拔，红色等高线落在你此刻的高度，实线是已经走过的地面，虚线是还没走到的地方；标记点沿曲线向上：0% 时停在海岸的山脚，走到 100% 时落在山巅。

- 首屏右侧的地形图由 Canvas 2D 现场绘制：种子固定的值噪声与分形、域扭曲叠加山脊与沟谷，生成一座不对称的岛，海岸因此有海湾与岬角；marching squares 提取等高线，再用一笔极淡的水域底色分出海岸。没有贴图、没有网络请求。
- 图纸语汇贯穿全站：石色纸与纸纹、墨绿等高线、朱红测绘标记、宋体标题与等宽小注、零圆角与发丝线、四角裁切标记；课程卡是索引卡（完成的卡盖一枚朱红小印），侧栏是图例，进度条是标尺，继续学习卡是深色的野外记录块。
- 主题键仍是 `ai_learning_visual_theme`，新增取值 `terrain`。切换不重建课程、不清除进度、不改变当前课程的阅读位置；重复点击当前主题不会跳回页首。
- 所有规则都以 `html[data-theme="terrain"]` 作用域隔离，经典与星空不受影响。

性能取舍：地形场与每一级等高线只在首次进入主题时计算一次并缓存，之后进度变化只重画路径；没有 `requestAnimationFrame` 循环、没有 WebGL、没有网络字体或图片，画布像素比上限为 2。地图仅在切换主题、调整窗口、进度变化时重绘，滚动阅读不触发任何背景绘制。

## 数据与性能

学习进度沿用 `ai_learning_tracker_v1` / `ai_learning_tracker_v2` 及原备份格式；主题单独存为 `ai_learning_visual_theme`。主题切换不重建课程、不清除任何学习记录。阅读课程时切换主题会尽量保持同一门课程的位置；重复点击当前主题不会跳回页首。

渲染限制像素密度与画布宽度，噪声、地表、法线与星云纹理一次生成并反复复用，相机轨迹每帧只计算一次，连续慢帧会自动降低分辨率，极慢设备会停止空闲自转；隐藏标签页暂停，经典模式不渲染，学习区镜头稳定后停止持续绘制，继续滚动课程也不触发背景重绘。减少动态效果偏好使用静止构图，滚动不触发无意义的重绘。WebGL 缺失或上下文丢失时使用静态空间色调，所有学习操作仍可用。

测试覆盖：原课程完整性与导入导出/迁移回归、主题持久化、五幕 WebGL 截图、320/390/768px 星空布局、经典八种屏宽、山海主题的三档断点、等高线重绘、0% 山脚标记与主题色元信息、减少动态效果、无 WebGL 降级。云环境使用 Chromium 软件图形渲染，不能据此保证实际硬件 60 FPS；发布前可在目标设备 DevTools Performance 中测量滚动帧率。

部署沿用原有 GitHub Pages 配置，直接提供静态文件，无需构建步骤或后端服务。

## 第二轮打磨与验证

- 区分海洋、岩质、带环冰巨星材质；调整星云的世界空间层次，减少星环采样混叠。
- 修复切换主题时课程阅读位置偏移；重复选择同一主题不产生副作用。
- 噪声纹理在多次主题切换间复用，WebGL 上下文恢复时重建失效资源。
- 验证经典/静态/学习区不持续重绘，以及 GPU 上下文丢失与恢复。
- 原经典样式、22 条课程记录和全部学习脚本与已发布基线逐字节一致；完整课程功能回归通过。

在当前 Chromium 软件图形环境中，动态场景帧率仍不能代表真实 GPU 表现；没有宣称已达到硬件 60 FPS。持续滚动学习内容无需重绘背景的行为已经通过绘制调用计数确认。

## 复跑回归测试

测试工具需要 Node.js 与 Playwright；网站运行本身不需要它们。

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/space-smoke.cjs
```

脚本自动启动临时本地服务器并在结束后关闭。若使用系统 Chromium，可通过 `CHROMIUM_PATH` 指定可执行文件。

## 第三轮性能优化

将地表、法线、星云计算移到初始化纹理缓存；使用 mipmap 减少缩小时的闪烁。相机轨迹和坐标基每帧计算一次，像素着色器负责视线与球面的真实三维求交、光照、大气、星环遮挡。

固定 960×640 分辨率、同一首屏、关闭自适应缩放，顺序运行于同一个 SwiftShader 软件渲染器：帧间隔中位数从 268.8 ms 降到 139.0 ms，减少约 48%；90 分位从 320.1 ms 降到 175.5 ms。这是当前软件环境的对照结果，并不等同于真实 GPU 的 60 FPS 验收。详细记录见 `VALIDATION.md`。

本地预览与 GitHub Pages 属于不同来源，浏览器不会自动共享进度。若要在本地使用已有记录，可先在原站导出，再在本地导入。
