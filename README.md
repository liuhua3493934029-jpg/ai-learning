# 学习手记 · 三主题

原生 HTML / CSS / JavaScript 学习站，提供经典、WebGL 星空与「织理 / WEFT」三套完整可切换主题。当前课程是 AI 工作流学习路线：20 门课程与 2 条跳过记录。

## 本地运行

在本目录执行：

```sh
python3 start-preview.py
```

脚本会打开 http://127.0.0.1:8000 。如未自动打开，可手动访问；通过「经典 / 星空 / 织理」选择器切换，手机织理主题使用右上角「主题」展开菜单。无需构建或下载第三方运行资源。星空主题使用现代浏览器的 WebGL 标准；本轮三套主题均使用 Chromium 实测。

## 文件

- `index.html`：保留原经典样式、全部课程与学习数据逻辑；接入三主题选择、滚动章节和主题预加载。
- `space.css`：隔离的星空主题、章节排版、移动端与无 WebGL 降级。
- `space.js`：原生 WebGL 着色器、三维球体光线求交、程序化地表/大气/星云、带阴影和遮挡的三维星环、连续相机轨迹与渲染调度，同时维护三主题状态与阅读位置。
- `weft.css`：隔离的织理主题，覆盖页头、学习概览、课程分类与卡片、备份、反馈、弹窗及移动端。
- `weft.js`：织理主题的短入场反馈、滚动书签与移动主题菜单；无 Canvas、无持续渲染循环。
- `start-preview.py`：仅使用 Python 标准库的本地预览启动器，可用 `--port 8001` 更换端口。
- `tests/space-smoke.cjs`：原经典、星空与学习数据回归。
- `tests/weft-smoke.cjs`：三主题往返、织理功能、响应式、移动菜单、阅读锚点、减少动态效果、空闲渲染与滚动性能回归。
- `tests/interaction-smoke.cjs`：全部可见目标尺寸、键盘焦点、弹窗、真实触控、存储失败降级与交互耗时检查。
- `tests/screenshots/`：经典、星空和织理在短屏、手机、平板、桌面及横屏下的实测截图。
- `tests/weft-performance.json`：本次云 Chromium 滚动帧间隔记录。
- `tests/interaction-performance.json`：课程更新和主题往返处理耗时记录。

五幕：深空苏醒 → 轨道穿行 → 行星近景 → 星云跃迁 → 原有学习区。首屏可直接跳至学习区，右侧章节导航可跳转，主题选择器始终可达。滚动保持浏览器原生行为。

## 数据与性能

学习进度沿用 `ai_learning_tracker_v1` / `ai_learning_tracker_v2` 及原备份格式；主题单独存为 `ai_learning_visual_theme`。主题切换不重建课程、不清除任何学习记录。阅读课程时切换主题会尽量保持同一门课程的位置；重复点击当前主题不会跳回页首。

渲染限制像素密度与画布宽度，噪声、地表、法线与星云纹理一次生成并反复复用，相机轨迹每帧只计算一次，连续慢帧会自动降低分辨率，极慢设备会停止空闲自转；隐藏标签页暂停，经典模式不渲染，学习区镜头稳定后停止持续绘制，继续滚动课程也不触发背景重绘。减少动态效果偏好使用静止构图，滚动不触发无意义的重绘。WebGL 缺失或上下文丢失时使用静态空间色调，所有学习操作仍可用。

织理主题不创建 WebGL 上下文，不加载图片、字体或其他第三方运行资源。纹理由静态 CSS 构成；只有主题切换和滚动时执行一次短任务，空闲时不请求动画帧。`prefers-reduced-motion` 下关闭入场穿梭与卡片位移动效，学习数据和全部操作保持可用。

测试覆盖：原课程完整性与导入导出/迁移回归、三主题持久化与往返切换、桌面和移动阅读位置、五幕 WebGL、320–1920px 十种织理宽度、320×568 短屏与 568×320 横屏、全部可见目标 44×44px、键盘焦点与弹窗、真实触控、存储失败降级、减少动态效果、无 WebGL 降级、空闲渲染循环与滚动帧间隔。云环境使用 Chromium，不能据此保证所有实际硬件均为 60 FPS；发布前可在目标设备 DevTools Performance 中复测。

部署沿用原有 GitHub Pages 配置，直接提供静态文件，无需构建步骤或后端服务。

## 第二轮打磨与验证

- 区分海洋、岩质、带环冰巨星材质；调整星云的世界空间层次，减少星环采样混叠。
- 修复切换主题时课程阅读位置偏移；重复选择同一主题不产生副作用。
- 噪声纹理在多次主题切换间复用，WebGL 上下文恢复时重建失效资源。
- 验证经典/静态/学习区不持续重绘，以及 GPU 上下文丢失与恢复。
- 原经典样式、22 条课程记录和全部学习脚本与已发布基线逐字节一致；完整课程功能回归通过。

在当前 Chromium 软件图形环境中，动态场景帧率仍不能代表真实 GPU 表现；没有宣称已达到硬件 60 FPS。持续滚动学习内容无需重绘背景的行为已经通过绘制调用计数确认。

## 复跑回归测试

测试工具需要 Node.js 与 Playwright；网站运行本身不需要它们。

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/space-smoke.cjs
node tests/interaction-smoke.cjs
node tests/weft-smoke.cjs
```

脚本自动启动临时本地服务器并在结束后关闭。若使用系统 Chromium，可通过 `CHROMIUM_PATH` 指定可执行文件。

## 第三轮性能优化

将地表、法线、星云计算移到初始化纹理缓存；使用 mipmap 减少缩小时的闪烁。相机轨迹和坐标基每帧计算一次，像素着色器负责视线与球面的真实三维求交、光照、大气、星环遮挡。

固定 960×640 分辨率、同一首屏、关闭自适应缩放，顺序运行于同一个 SwiftShader 软件渲染器：帧间隔中位数从 268.8 ms 降到 139.0 ms，减少约 48%；90 分位从 320.1 ms 降到 175.5 ms。这是当前软件环境的对照结果，并不等同于真实 GPU 的 60 FPS 验收。详细记录见 `VALIDATION.md`。

## 第四轮：织理 / WEFT

设计命题是“把零散课程织成完整工作流”。经线对应学习路线，纬线对应一次次实践，课程卡片因此采用织样纸卡而非通用圆角组件。

- 色板：冷灰亚麻 `#e7e8e1`、纸卡 `#f3f2ea`、墨色 `#1b3038`、经线靛蓝 `#203f4a`、纬线茜草红 `#a33f2c`、辅助青蓝 `#315d6d`。
- 字体：Bahnschrift / DIN Alternate 与系统中文无衬线共同承担展示和正文；等宽字体只用于真实序号与计量。
- 版式：桌面课程以 7/5、5/7 交替的双列织样排列，保持每行信息完整；平板转为等宽双列，手机转为单列。
- 交互：主题进入时只播放一次梭线；宽屏右侧书签随页面滚动；手机用「主题」按钮展开选择器，支持点击外部与 Escape 关闭；完成、筛选、导入导出仍使用原有真实功能，没有演示按钮。
- 隔离：新样式全部限定在 `html[data-theme=weft]`，经典与星空原实现保留。主题值仍写入原 `ai_learning_visual_theme`，学习数据键与备份格式不变。

## 第五轮：视觉与交互质量审查

- 修复窄屏固定主题面板遮挡进度和筛选的问题：桌面保留固定三主题，手机织理改为紧凑菜单，不再占用底部内容区。
- 手机菜单支持键盘展开、真实触控、外部点击与 Escape 关闭、选择后的焦点返回，以及视口变化时自动收起。
- 全部可见操作目标不小于 44×44px；无障碍跳转链接和备份说明入口也纳入检查。
- 验证课程重绘后的焦点保留、弹窗键盘路径、存储被禁用时的可用界面，以及移动端阅读锚点。
- 人工复核经典、星空原界面和织理全部课程分组，包含 320×568、390×844、568×320、768px 与 1440px。

本地预览与 GitHub Pages 属于不同来源，浏览器不会自动共享进度。若要在本地使用已有记录，可先在原站导出，再在本地导入。
